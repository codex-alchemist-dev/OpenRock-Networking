# OpenRock-Networking

A scriptevent-based request/response API over Bedrock's real scriptevent mechanism, with chunking for payloads over the real scriptevent size limit and a timeout-based request() helper.

Part of the [OpenRock](https://github.com/codex-alchemist-dev/OpenRock) Minecraft Bedrock mod-packaging ecosystem - a Codex Alchemist project, under Fireball Everything. Consumed as a real git submodule at `libs/networking` in the main OpenRock repo, and directly `npm require`/`import`-able (real top-level CommonJS exports, esbuild-CJS/ESM-interop-compatible) by any mod's own build-time kernel registration or real in-game script.
